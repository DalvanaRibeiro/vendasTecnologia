# Academia Comercial — Técnico em Desenvolvimento de Sistemas

Site estático pronto para GitHub Pages.

## Publicar
1. Extraia os arquivos deste ZIP para a raiz do repositório.
2. GitHub → Settings → Pages → Deploy from a branch → main / (root).
3. Aguarde a publicação.

## Conteúdo
- Três personagens ilustrados em SVG, sem fotos reais.
- Abordagens consultivas por nível de conhecimento.
- Seis objeções comuns com respostas profissionais.
- Matriz TDS de referência com 1.216 horas (UC17 dividida em duas partes).
- Corpo docente sem fotos, conforme material fornecido anteriormente.

Antes da divulgação externa, confirme versão do plano, equipe docente, dados institucionais e condições de matrícula.
